# CySec-Homelab
Cybersecurity homelab built on VirtualBox to develop SOC analyst skills. Features a pfSense firewall, Windows Server 2025 Active Directory domain, Windows 11 endpoint with Sysmon, Splunk SIEM, and Kali Linux attacker. Used to simulate attacks, analyze logs, and build detections. Documented as a hands-on SOC Level 1 portfolio.
